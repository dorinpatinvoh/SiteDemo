# Prompts pour générer les visuels (aucun texte incrusté)

Toutes les images doivent être **sans logo, sans texte et sans watermark**, photoréalistes, éclairage professionnel. Générer des images WebP ou JPG compressées pour le web (idéalement 150–350 Ko chacune). Enregistrer sous les noms indiqués dans les dossiers `assets/` correspondants.
